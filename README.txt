ACNM 임상통계 해설 노트 — 설치형 웹앱(PWA)
============================================
1) 이 폴더의 파일을 "모두, 같은 폴더에" 웹에 올립니다 (GitHub Pages 권장).
2) 올라간 주소를 폰/PC 브라우저로 열고 "앱 설치"(아이폰은 사파리 공유 → 홈 화면에 추가).
3) 설치 후에는 인터넷 없이도 전부 열립니다.

자세한 단계는 같은 폴더의 설치안내.html 을 브라우저로 열어 보세요.

포함 파일
  index.html              앱 본체(1~4장 + 보충 + SPSS 매뉴얼 전체, 그림 포함)
  manifest.webmanifest    앱 이름/아이콘 정보
  sw.js                   오프라인 저장
  icon-192.png / icon-512.png / icon-maskable-512.png / icon-180.png / favicon-32.png
  설치안내.html            설치 및 사용 안내
